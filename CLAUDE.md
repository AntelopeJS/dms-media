# @antelopejs/dms-media

> AntelopeJS DMS module providing an asset/media library: upload, folders, delivery derivatives and light image editing (crop/rotate), with per-folder permissions that reuse the DMS authorization system. Ships a Finder-style file explorer and an `AssetType` form field. See [docs/PRD.md](./docs/PRD.md) for the full spec.

See [AGENTS.md](./AGENTS.md) for code conventions and guidelines.
