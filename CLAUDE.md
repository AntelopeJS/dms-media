# dms-media

> pnpm workspace for the AntelopeJS DMS media module. `packages/dms-media` (`@antelopejs/dms-media`) provides an asset/media library: upload, folders, delivery derivatives and light image editing (crop/rotate), with per-folder permissions that reuse the DMS authorization system, and ships a Finder-style file explorer. `packages/interface-dms-media` (`@antelopejs/interface-dms-media`) is the interface it implements: the `AssetType` form field and the folder bindings consumers declare.

See [AGENTS.md](./AGENTS.md) for code conventions and guidelines.
