# Activity

The Activity page (`/modules/media/activity`) lists every write in the library: uploads, edits, moves, deletions, visibility changes and folder changes, grouped by day and filterable by kind.

![The Activity page](../images/activity.png)

Events are kept 90 days. They also feed the overview, the History tab of each file and the upload batches.
